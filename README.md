# Graph Database Analysis – Neo4j

## Project Overview

This project explores the application of graph databases using Neo4j to analyse complex relationships and interconnected data. Using the Heisters dataset, the project examines how graph databases differ from traditional relational SQL databases and demonstrates how relationships between individuals, friendships, and travel preferences can be explored through graph-based queries. It also investigates real-world industry applications, including network analysis, criminal intelligence, and recommendation systems.

## Objectives

- Understand the differences between graph databases and traditional SQL databases.
- Explore graph database structures using nodes, relationships, and properties.
- Analyse connections and friendships within the Heisters dataset.
- Identify hidden relationships through shared travel destinations.
- Explore recommendation patterns based on common preferences.
- Evaluate challenges associated with graph database performance and scalability.
- Understand the practical applications of graph databases across industries.

## Key Findings

- **Database Comparison:** Graph databases represent interconnected data through nodes and relationships, reducing the need for complex JOIN operations required in traditional relational databases.
- **Relationship Analysis:** Neo4j queries identified friendships and connections between individuals in the Heisters dataset.
- **Hidden Connections:** Shared travel destinations helped identify potential associations and common travel patterns between individuals.
- **Recommendation Patterns:** Common travel preferences demonstrated how graph databases can support recommendation systems based on shared interests.
- **Scalability Challenges:** Deep graph traversals across large networks can affect query performance, highlighting the importance of indexing, filtering, and query optimisation.
